# App — Hardware Service Decision Copilot

This is the application built during the course: a multimodal AI assistant for support
employees to file and resolve hardware complaint/return cases (see `../docs/PRD.md` and
`../docs/ADR/`).

Bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app)
per `docs/ADR/000-main-architecture.md` (Decision D-2) and `docs/ADR/002-frontend.md`
(initialization sequence).

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `src/app/page.tsx`. The page auto-updates as you edit
the file.
